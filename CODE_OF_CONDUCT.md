# Code de conduite

Le projet ReUse-CH réunit des personnes issues d'administrations, d'entreprises, du monde académique et de la société civile. Nous nous engageons à offrir un environnement ouvert, accueillant et respectueux pour toutes et tous.

## Nos engagements

- Faire preuve de respect et de bienveillance dans tous les échanges (issues, pull requests, discussions, événements).
- Accueillir les débutant·e·s et les points de vue différents ; critiquer les idées, jamais les personnes.
- Accepter les critiques constructives avec ouverture.
- Privilégier l'intérêt du bien commun numérique sur les intérêts particuliers.

## Comportements inacceptables

- Propos ou comportements discriminatoires, harcelants, insultants ou dénigrants.
- Attaques personnelles ou politiques.
- Publication d'informations privées d'autrui sans consentement.
- Promotion commerciale sans lien avec l'objet du projet.

## Application

Les mainteneur·euse·s du projet peuvent modérer, éditer ou refuser toute contribution contraire à ce code de conduite. Les situations problématiques peuvent être signalées de manière confidentielle aux mainteneur·euse·s via GitHub.

Ce code de conduite s'applique à tous les espaces du projet, en ligne comme en présentiel.
