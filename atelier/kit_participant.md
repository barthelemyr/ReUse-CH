# ReUse-CH en une page – Kit participant

## C'est quoi ?

**ReUse-CH** est un cadre **volontaire, flexible et complémentaire** aux stratégies fédérales et cantonales, qui aide chaque administration publique suisse, quelle que soit sa taille, à réussir une **transformation numérique responsable** : réutiliser, partager et sécuriser plutôt que racheter ou redévelopper chacun dans son coin.

Version 0.1 : une **base de travail** que vous êtes invité·e·s à amender aujourd'hui. Rien n'est figé, tout se discute.

## Les cinq réflexes

1. **Réutiliser avant tout** : vérifier l'existant (interne, autres communes, canton, open source) avant d'acheter ou de développer.
2. **Mesurer pour améliorer** : quelques indicateurs utiles plutôt que tout mesurer.
3. **Partager pour économiser** : code, cahiers des charges, contrats, retours d'expérience.
4. **Concevoir pour l'utilisateur** : accessibilité, inclusion, tests avec les usagers.
5. **Sécuriser par défaut** : protection des données et cybersécurité dès la conception.

## Ce qu'on attend de vous aujourd'hui

- Votre **regard de praticien·ne** : dites ce qui ne marcherait pas chez vous, c'est le retour le plus précieux.
- Un **cas réel** : le projet numérique que vous avez apporté servira à tester la checklist.
- Vos **priorités** : 3 gommettes pour dire de quels outils votre commune a le plus besoin.
- Si le cœur vous en dit, un **engagement** pour la suite, même modeste.

## Le programme

| | |
|---|---|
| Le cadre en 20 minutes | positionnement, réflexes, votes |

| Checklist sur cas réels | en groupes, sur vos projets |
| Stations de co-construction | réutilisation, prestataires, souveraineté |
| Priorisation et engagements | vos gommettes, vos suites |
